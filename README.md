# arXiv Human-Centric Vision Weekly

面向人体中心计算机视觉研究的 arXiv 中文论文周报。

本项目定期筛选 [arXiv cs.CV](https://arxiv.org/list/cs.CV/recent) 中与人体及人的行为理解相关的新论文，翻译论文题目和摘要，并提供对应的 arXiv 原文链接，方便快速跟踪研究进展。

## 关注方向

- 动作识别、活动理解与动作预判
- 手势识别、手语识别与手语翻译
- 二维/三维人体姿态估计
- 手部姿态、手—物交互与第一视角视觉
- 人体运动生成、编辑与预测
- 人—人交互和多人行为理解
- 三维人体重建、人体建模与可动画数字人
- 人体中心视觉基础模型
- 光照估计、重光照及与人体建模相关的光照研究

## 标记说明

周报中的 **★** 表示论文已明确提供公开源代码仓库。

仅提供项目主页、在线演示，或仅承诺未来开放代码的论文不加星标。星标代表代码在整理时公开可访问，不代表本项目对代码质量、许可证或可复现性作出保证。

## 筛选与整理方式

1. 获取指定自然周内分类包含 `cs.CV` 的 arXiv 新提交记录。
2. 根据题目和摘要进行关键词初筛。
3. 人工排除仅偶然提及关键词的论文，例如相机位姿估计、物体位姿估计和普通点云配准。
4. 对入选论文的题目及摘要进行中文翻译，并保留作者、主题和 arXiv 链接。
5. 检查论文页面是否明确提供公开代码仓库，并添加 ★ 标记。

日期以 arXiv 首次提交时间为准。arXiv 是预印本平台，收录不等同于论文已经通过同行评审或正式发表。
